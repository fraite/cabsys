# CabSys

A power cable system design program, that includes a cable design and current rating function.

CabSys is unfinished and being developed. This version (CabSys) includes files from PyCharm and UV.

## Description

CabSys allows power cable systems, generally greater than 33 kV, to be designed. CabSys has the following features:
* Cable design
* Cable installation design with an arbitrary number of cable circuits, with different cable voltages and designs
* Current ratings to IEC 60287 standards, with many options to alter the method

The program is not finished:
* The program may crash or perform unexpectedly
* The results may be wrong
* Data saved in the program may not reload correctly

## Objectives

The program objectives are:
* Carry out current rating calculations to IEC 60287 / TB 880 that can be verified
* Use other methods to calculate cable system performance
* Be easy to use
