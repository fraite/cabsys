Multiple sheath/screen heat loss

Symbols: N/A

Calculate sheath/screen heat loss for each metal sheath/screen.

For cables with more than one metal sheath/screen, calculate the sheath/screen loss for each metal sheath/screen. Otherwise, all the metal sheath/screens are combined into one sheath/screen and a single sheath/screen loss is calculated. Note: only one metal sheath is allowed, as eddy sheath losses (lambda1'') can not be split between layers but tape screens and wire screens do not have any eddy sheath/screen losses so multiple layers of tape and wire screens are possible.

According to IEC 60287-1-1:2023, the metal sheath/screens are combined. To calculate ratings to IEC 60287 ensure that this config setting is off and that the combi_sheath_iec configuration setting is selected to use the method of combining the sheath/screen resistances to IEC 60287.

TB 880 Ed 1 recommends that sheath/screen loss for each metal sheath/screen is calculated. Setting this configuration flag to True and the combi_sheath_iec configuration setting to False will then calculate the sheath/screen loss for each metal sheath/screen.
