Single T3 thermal resistivity

Symbols: N/A

Calculate T3 with a uniform thermal resistivity.

According to IEC 60287-2-1:2023, T3, the thermal resistance of the serving (outer layer), is calculated using a uniform thermal resistivity defined by the base material. This does not take account of the different thermal resistivity of other layers such as the semiconducting layer. TB 880 Ed 1 recommends that the resistance of each layer is calculated and IEC 60287-2-1:2023 does note that this is a possible method to calculate T3. Setting this configuration flag to False will calculate the thermal resistance of each layer and sum the values to get a total T3.
