Non-metal screen isotherm

Symbols: N/A

Non-metal screens for trefoil touching cables are treated as an isotherm.

According to IEC 60287-2-1:2023 Section 4.2.4.3.4, for the external thermal resistance for trefoil touching single core cables no modification to the thermal resistance of the insulation (T1) or serving (T3) is made. This appears to be an error since IEC 60287-2-1:2023 Section 4.2.4.3.2 and 4.2.4.3.3 do make modifications to T1 and T3. Setting non_metal_screen_isotherm to False makes calculations ignore IEC 60287 and make modification to T1 and T3 for non-metal covered cables as if they were part metal covered cables.

For further information see the design manual.
