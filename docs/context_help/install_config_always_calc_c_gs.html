Always calculate C_gs

Symbols: N/A

For lead sheathed and small aluminium sheathed cables C_gs can be taken as unity.

According to IEC 60287-1-1:2023 Section 5.3.7.1, for eddy current losses of single core lead sheathed cables and small aluminium sheathed cables the value of C_gs can be taken as unity. When this flag is set to True the simplification suggested by IEC to set the value to unity is ignored and the value of C_gs is always calculated, which should be slightly more accurate.
