Rating Type

Symbols: N/A

The type of rating (for example: continuous).

Current rating calculations can be split into two main types of calculations, continuous current ratings and transient current ratings. Continuous current ratings assume that the cable temperatures have all reached steady state and the conductor currents will also be a steady state value. Transient calculations vary the conductor current over time and may also vary the rating parameters (such as ambient temperature) over time too.

The transient ratings can be further subdivided so that three sub rating types can be defined:

  • Emergency rating: a current rating used during an emergency that allows the conductor temperature to be above the normal maximum continuous conductor temperature. For an emergency rating, a pre-emergency steady state has been achieved with a defined pre-emergency conductor current or defined pre-emergency temperatures. The cable conductor current is then changed (generally raised) to a constant value for a set time period (the emergency period). Normally the calculation calculates the maximum permissible emergency current ratings, but alternatively the conductor temperature at the end of the emergency period can be calculated.
  • Transient rating: conductor temperatures for a given conductor current load pattern (load curve) are calculated, including the maximum conductor temperature during the load pattern. A preload prior to the load curve can be defined. If the maximum conductor temperature is defined, the maximum magnitude of the load pattern can be calculated.
  • Cyclic rating: conductor temperatures for a given conductor current load pattern (load curve) that repeats are calculated, including the maximum temperature during the load pattern. If the maximum conductor temperature is defined, the maximum magnitude of the load pattern can be calculated.

For further information on continuous current ratings, see Section 1.1.1 of the design manual and on transient ratings, see Section 1.1.2 of the design manual.
