Foil eddy loss radial thickness

Symbols: N/A

Ignore the eddy current losses for foil screens (sheaths) less than given thickness.

According to IEC 60287-1-1:2023, for cables with a wire screen and foil screen over the wires the eddy current losses are considered negligible (ignored). The thickness that a screen is considered a foil rather than a metal sheath is not given in IEC 60287-1-1:2023. This thickness is defined by this configuration parameter.

Note: it is assumed if there is no wire screen that a foil screen will still be considered to have negligible eddy current losses.

For further information on negligible eddy current losses, see Section 1.1.1 of the design manual and on transient ratings, see Section 1.1.2 of the design manual.
