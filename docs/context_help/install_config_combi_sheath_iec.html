Combined sheath/screen to IEC

Symbols: N/A

Combine metal sheath/screen to only one sheath/screen heat loss for each cable.

WARNING: IEC calculation not correctly implemented. The IEC method of calculating combined sheath resistance is not correct and the thernal resistance between sheath/screens is ignored.

For cables with more than one metal sheath/screen, all the metal sheath/screens are combined into one sheath/screen and a single sheath/screen loss is calculated. Note: only one metal sheath is allowed, as eddy sheath losses (lambda1'') can not be combined but tape screens and wire screens do not have any eddy sheath/screen losses so multiple layers of tape and wire screens can be combined.

According to IEC 60287-1-1:2023, the metal sheath/screens are combined. The method of calculating the combined sheath/screen electrical resistance is specified, which is simplified for hand calculations with an average value of thermal resistance temperature coefficient used. To calculate ratings to IEC 60287 ensure that this combi_sheath_iec configuration setting is selected to use the method of combining the sheath/screen resistances to IEC 60287.

TB 880 Ed 1 recommends that sheath/screen loss for each metal sheath/screen is calculated. To use TB 880 the recommended method set this combi_sheath_loss setting to False and the multi_sheath_lambda to True.

If this combi_sheath_lambda setting is False and the multi_sheath_lambda setting is False, the sheath/screen losses will be calculated as a combined metal/screen but with the metal sheath/screen resistance calculated with the thermal resistance temperature coefficient of each sheath/screen used rather than an average.
