Multiple sheath/screen accuracy

Symbols: N/A

Accuracy of metal sheath/screen temperature.

For cables with more than one metal sheath/screen, if the metal sheath/screen heat loss (lambda_1) is calculated for each sheath/screen individually then the sheath/screen temperature has to be calculated for each sheath/screen. To calculate the temperature the sheath/screen loss is required, so an iterative process is used. The iteration will continue until the difference between the iterated sheath/screen temperature is less than the specified value.

Note, by putting a large value for the sheath/screen accuracy the initial value will be used, which assumes no heat loss from any of the sheaths/screens.
